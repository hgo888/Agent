## 二、原来为什么跑不起来（4 个阻塞）

1. **自带 `.venv` 是 Python 3.14 的空壳**，`requirements.txt` 里的 `numpy==1.26.4`、`graphrag==2.7.0` 等在 3.14 上装不了。
2. **路径全写死成 Linux 绝对路径** `/root/autodl-tmp/multimodel_RAG/...`，`load_dotenv` 静默失败导致 Key 为 `None`。
3. **faiss 在 Windows 打不开含中文的绝对路径**（项目路径含「AI应用」「【…】」），报 "could not open ... No such file or directory"。
4. **GraphRAG 索引没随项目提供**（`output/` 五个 parquet 全缺），且 `graphrag` 包未安装。

### 源码补丁（改在 site-packages 里）

DeepSeek **不支持** `response_format={"type":"json_schema"}`（报 `This response_format type is unavailable now`），而 GraphRAG 的社区报告生成强制使用 pydantic 结构化输出，直接跑必挂。补丁思路是「对外发 `json_object`，对内保留 pydantic 解析」：

`graphrag/language_model/providers/litellm/chat_model.py` → `achat()` 里，调用 `acompletion` 前把 pydantic 类替换成 `{"type": "json_object"}`，`parsed_response` 仍按模型类实例化。

> ⚠️ 这个补丁在 `site-packages` 里，**重装/升级 graphrag 会丢失**，需要重新打。
